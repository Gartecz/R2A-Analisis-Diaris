# Anàlisis del bot R2-A

Repositori exclusiu per als informes automàtics del bot R2-A.

- No conté codi del bot.
- No conté credencials, logins ni claus.
- No pot enviar ordres a MT5.
- Cada informe diari viu a `analisis/YYYY/MM/YYYY-MM-DD.json`.
- Cada informe setmanal viu a `setmanals/YYYY/YYYY-Www.json`.
- La web pública només llegeix aquests fitxers.

Els informes diaris han de complir `schema/analysis.schema.json` i els setmanals
`schema/weekly-analysis.schema.json`.
