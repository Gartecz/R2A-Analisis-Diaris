# Regles obligatòries

Aquest repositori només admet informes diaris i setmanals de lectura.

## Permès

- Crear o actualitzar `analisis/YYYY/MM/YYYY-MM-DD.json`.
- Crear o actualitzar `setmanals/YYYY/YYYY-Www.json`.
- Llegir l'esquema i informes anteriors.

## Prohibit per a l'agent d'anàlisi

- Incloure logins, contrasenyes, tokens, claus o dades personals.
- Crear codi executable, workflows o scripts.
- Esborrar informes.
- Escriure fora de `analisis/` i `setmanals/`.
- Inventar dades absents.
- Operar o intentar controlar MT5.

Cada informe ha d'indicar si les dades són antigues, incompletes o inaccessibles.

Els scripts de validació i agregació són mantinguts separadament pels administradors del repositori.
